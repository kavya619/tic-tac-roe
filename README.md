# Tic-Tac-Toe Game
Welcome to the Tic Tac Toe Game repository! This project is a simple implementation of the classic Tic Tac Toe game, built using HTML, CSS, and JavaScript. It provides a fun way to play the game right in your browser.

Features
i)Interactive Gameplay: Play against a friend on the same device.
ii)Responsive Design: The game is designed to work on various screen sizes.
iii)Dynamic User Interface: Highlights the winner or a tie when the game ends.
iv)Reset Functionality: Allows you to reset the board and start a new game.

Technologies Used
i)HTML: For structuring the game interface.
ii)CSS: For styling the game board and creating a visually appealing design.
iii)JavaScript: For implementing the game logic and interactivity.
